## HyperTile 0.3.0

The first public release.

- Tiles every window automatically, in Grid, Columns, Rows or Side layouts
- Optional virtual desktops, with a four-finger swipe between them
- Keyboard shortcuts to swap, focus, float and resize windows
- Windows with a minimum or fixed size get room in the layout
- Picks up trackpads connected after launch, and after sleep
- Uses less energy when nothing on screen changes
- Offers to move itself to Applications
- Licence activation in the welcome tour and Settings → Licence
